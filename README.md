
# 💊 MedApp - Medication Reminder App

**MedApp** is a user-friendly medication reminder application designed to help users manage their medicine schedule efficiently.  
It is specifically tailored for middle-aged and elderly users, providing a smooth and simple interface without requiring authentication.

---

## 🚀 Features

- 📅 Add medicines with daily, weekly, monthly schedules
- ⏰ Set reminders at specific times
- 🔔 Alarm notifications for medicine intake
- 📖 Medicine history tracking (taken or missed doses)
- 🗂️ “My Medicines” page for active medications
- 🗂️ “History” page for past medication records
- 🛠️ Local storage with Hive for offline use
- 🕹 Simple UI design for ease of use
- 🌐 Turkish language support only

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)
- **Local Storage:** Hive
- **Notifications:** Flutter Local Notifications
